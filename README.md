# Algorithms

Repositório de estudos de **estruturas de dados**, **algoritmos** e **SQL**.

Aqui ficam só os meus exercícios e tentativas. Não é um projeto que possa ser utilizado por outras pessoas, apenas anotar meu andamento nos estudos e caso queira, comparar minhas respostas com as suas.

## Como eu estudo

O Claude Code é o meu **professor** neste repositório:

- Ele me ajuda a entender a lógica e a escrever o código por conta própria.
- Ele explica conceitos, dá dicas e aponta onde estão os erros.
- Ele **nunca entrega a resposta pronta**.

O objetivo é aprender a fazer algoritmos melhores, não só ter exercícios resolvidos.
